## Session: 前端路由/导航/页面渲染 Bug 修复

### 修复内容

**1. tools → tool 改名**
- 目录 `pages/devops/tools/` → `pages/devops/tool/`
- 路由常量 `TOOLS_*` → `TOOL_*`
- 导航栏 "Tools" → "Tool"

**2. import 在 `<script setup>` 外面（核心 bug）**
- 涉及文件：`admin/system/user/view.vue`、`admin/project/view/index.vue`、`admin/system/dept/view/index.vue`、`user/project/[id]/info/index.vue`
- `import` 语句写在 `<script setup>` 标签外面，不被编译，常量为 `undefined`
- 导致页面 500 报错：`Cannot read properties of undefined (reading 'PROJECT_LIST')`
- **排查方法：** `head -1` 检查是否以 `import` 开头且前几行无 `<script` 标签

**3. 导航栏分组自动折叠**
- User/Department/Project 的 `:open` 用 `includes(LIST_PATH)`
- 点 view 页面时路径不含 `list`，`open` 变 false 导致折叠
- 全部改成 `startsWith('/admin/system/user')` 前缀匹配

**4. 404 页面 "Back to Home" 导航不同步**
- `clearError({ redirect: '/' })` → `clearError({ redirect: authStore.homeRoute })`
- `redirect-home.global.ts` 加路径同步：访问 `/admin/*` 自动 `setConsoleRole('admin')`

**5. 页面切换后数据不显示（KeepAlive）**
- Nuxt 3 默认 KeepAlive，`onMounted` 只触发一次
- 创建了 `composables/usePageRefresh.ts`：`onMounted` + `onActivated` + `watch(route.fullPath)`
- 后来发现是 import bug 导致的错误渲染，回滚到 `b4a3115`（确认没问题的版本）后问题消失
- `usePageRefresh` 仍保留在代码中作为防御措施
