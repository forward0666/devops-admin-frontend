# 2026-05-12

## 前端布局修复：表格页面底部灰色空白 + 数据不撑满

### 问题
Cloudflare 系列页面（DNS/SSL/Zone/Security/Cache）底部有大片灰色空白，数据表格不填满视口。

### 根因（多层叠加）
1. **布局高度链断裂** — `@layouts` 的 VerticalNavLayout 用 `min-block-size: 100dvh`（非固定高度），导致 flex 子项不会被压缩，内容溢出
2. **footer 占空间** — `.layout-footer` 的 `.footer-content-container` 有固定 56px 高度（`$layout-vertical-nav-footer-height`）
3. **`max-height: calc(100vh - ???px)` 锁死表格高度** — 各页面 scoped style 里 `.v-table__wrapper` 有 `max-height: calc(100vh - 200px)`，减去值不对导致表格高度不够或溢出
4. **`padding-block: 1.5rem` 上下都有** — `.layout-page-content` 上下等量 padding

### 修复方案

#### 1. 全局 SCSS（`@layouts/styles/_default-layout.scss`）
```scss
// html/body 高度 100%
html, body, #__nuxt { block-size: 100%; margin: 0; }

// layout-content-wrapper 改固定高度
// @layouts/components/VerticalNavLayout.vue 里
// min-block-size: 100dvh → block-size: 100dvh + overflow: hidden

// footer 隐藏（没有使用）
.layout-footer { block-size: 0; overflow: hidden; }

// flex 高度传递链
.layout-page-content {
  flex-grow: 1;
  display: flex;
  flex-direction: column;
  min-block-size: 0;
  overflow: hidden;
  
  .page-content-container {
    flex: 1;
    min-block-size: 0;
    display: flex;
    flex-direction: column;
    
    // 穿透两层包装 div
    & > *, & > * > * {
      flex: 1;
      min-block-size: 0;
      display: flex;
      flex-direction: column;
    }
  }
}
```

#### 2. VerticalNavLayout.vue
- `.layout-content-wrapper`: `min-block-size: 100dvh` → `block-size: 100dvh` + `overflow: hidden`

#### 3. 各页面模板（dns/ssl/cache/zone/security/domain）
- 外层 `<div>` 加 `style="display: flex; flex-direction: column; flex: 1; min-height: 0;"`
- 筛选栏 VCard 加 `style="flex-shrink: 0;"`
- 数据 VCard 加 `style="display: flex; flex-direction: column; flex: 1; min-height: 0;"`
- 表格容器 `<div>` 加 `style="flex: 1; min-height: 0; overflow-y: auto;"`（**外层 div 负责滚动**）
- VTable **不参与 flex**（不加 display:flex/flex:1），让表格自然撑开

#### 4. Scoped style
- **删除** `max-height: calc(100vh - ???px)` 
- 改成：
```scss
.sticky-table {
  :deep(.v-table__wrapper) {
    overflow-y: visible;  // 让外层 div 管滚动
  }
}
```

### 关键教训
1. **VTable 不适合参与 flex 拉伸** — Vuetify VTable 内部结构复杂，`display: flex; flex-direction: column` 在 VTable 上会导致 `v-table__wrapper` 的滚动失效
2. **滚动交给外层 div** — `flex: 1; min-height: 0; overflow-y: auto` 的 div 包裹 VTable，比强行让 VTable 自己滚动更可靠
3. **`min-block-size: 0` 是 flex 收缩的关键** — 没有 `min-height: 0`（或 `min-block-size: 0`），flex 子项默认 `min-height: auto` 不会收缩到内容以下
4. **别用 `calc(100vh - ???px)`** — 硬编码偏移量维护成本高，侧边栏折叠/展开都会导致值不对
5. **调试方法**：给每层 div 加不同颜色 border，快速定位哪层没撑满
